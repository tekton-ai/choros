# Choros

Choros (χορός, "coordinated chorus") — an agent-first coding platform. One workspace for Claude Code, Codex, and any coding agent, run in parallel across isolated git worktrees.

**Latest release:** [`desktop-v0.1.0`](https://github.com/tekton-ai/choros/releases/tag/desktop-v0.1.0) — macOS (arm64 / x64) and Linux (x86_64) desktop app.

## Building

```bash
./.choros/setup.local.sh
bun run dev
```

## SDLC

Substantial changes flow through the [AI-Native SDLC](https://claude.com/blog/the-ai-native-sdlc-playbook) — intent, spec, plan committed under `docs/sdlc/<feature-slug>/` before code lands.
