Choros

Bring any coding agent. Orchestrate them all.

One workspace for Claude Code, Codex, and any coding agent — run in parallel across isolated git worktrees.

Choros ships as a desktop app with a bundled CLI. Every task runs in its own git worktree so agents don't step on each other. Sessions, automations, and terminals are first-class — orchestrate them from the sidebar or drive them from the shell.
